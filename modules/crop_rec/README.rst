Crop mode recording
===================

以裁切模式录制RAW视频,获得更高分辨率
into 3x (1:1) crop modes, by tweaking the sensor registers.

All other behaviors are the same as with Canon's 1080p/720p
implementation: resolution, H.264, RAW, audio, HDMI, preview,
overlays and so on.
